# Математическое описание программы

Используются следующие формулы для решения СЛАУ вида $Ax = b$:

### **Метод Гаусса (Классический)**

**Прямой ход:** Исключение элементов под главной диагональю для каждого шага $k$ (от $1$ до $n-1$) и строк $i$ (от $k+1$ до $n$):

1. Коэффициент обнуления:

$$factor = \frac{a_{ik}}{a_{kk}}$$

2. Преобразование элементов матрицы:

$$a_{ij} = a_{ij} - factor \cdot a_{kj}, \quad j = k, \dots, n$$

3. Преобразование правой части:

$$b_i = b_i - factor \cdot b_k$$

**Обратный ход:** Нахождение неизвестных $x_i$ от $n$ до $1$:

$$x_i = \frac{1}{a_{ii}} \left( b_i - \sum_{j=i+1}^{n} a_{ij} x_j \right)$$

---

### **Метод Гаусса с частичным выбором**

Перед каждым шагом $k$ выполняется поиск строки $p$, содержащей максимальный по модулю элемент в текущем столбце (ведущий элемент):

$$|a_{pk}| = \max_{k \le i \le n} |a_{ik}|$$

Если $p \neq k$, происходит перестановка строк: $Row(k) \leftrightarrow Row(p)$. Это гарантирует, что $|factor| \le 1$.

---

### **LU-разложение**

Матрица $A$ раскладывается на $L$ (нижняя треугольная) и $U$ (верхняя треугольная).

**Нахождение элементов $U$ и $L$:**

*   $l_{ii}=1$

*   Для $j \ge i$:
  
$$u_{ij} = a_{ij} - \sum_{k=1}^{i-1} l_{ik} u_{kj}$$

*   Для $i > j$:
  
$$l_{ij} = \frac{1}{u_{jj}} \left( a_{ij} - \sum_{k=1}^{j-1} l_{ik} u_{kj} \right)$$

---

### **Решение треугольной матрицы**

1. Решение $Ly = b$ (прямая подстановка):

$$y_i = b_i - \sum_{j=1}^{i-1} l_{ij} y_j, \quad i = 1, \dots, n$$

2. Решение $Ux = x$ (обратная подстановка):

$$x_i = \frac{1}{u_{ii}} \left( y_i - \sum_{j=i+1}^{n} u_{ij} x_j \right), \quad i = n, \dots, 1$$

---

### **Генерация случайных чисел**

Для создания матрицы $A$ программа генерирует сид (автоматически или по запросу пользователя) в пределах от $$100\ 000$$ до $$10\ 000\ 000$$, который участвует в процессе генерации данных. Пределы возможных чисел матрицы (`low_number` и `high_number`) по умолчанию установлены на $$1$$ и $$1000$$, но пользователь может задать собственные значения при необходимости.
