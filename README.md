# Информация по работе с программой
  1) Скачать файлы
  2) Собрать их

  
    make  
  
  3) Запустить программу

    ./app

  4) Последующие шаги написаны в интерфейсе

    Введите размер матрицы:

    === Возможные команды ===
     1) Сгененировать сид
     2) Задать сид
     3) Сгенерировать матрицу
     4) Вывести LU-разложение
     5) Замерить время
     6) Выбрать диапазон чисел в матрице
     0) Выход
    
    Выберите команду:
   
  5) После работы с программой провести очистку

    make clean
